# 表情包

她把表情包当"语气"用：一句话说完，可能再补一张贴纸。
发不发、发哪张由她自己判断（按下面 `tags` 里的情绪标签挑），你不用管。

## 现在库里有

**30 张**，分布 `笑 4 / 无语 3 / 骂 7 / 委屈 6 / 得意 5 / 撒娇 5`。

## 怎么加一张图

1. 把图片丢进这个目录（`.png` / `.jpg` / `.gif` / `.webp`，**建议单张 ≤ 1MB**）
2. 在 `index.json` 的 `items` 里加一行：

```json
{ "file": "你的文件名.jpg", "tags": ["无语"], "note": "这张图长什么样、什么时候用" }
```

3. 不用重启，下一次挑图就会读到（程序按 `index.json` 的修改时间自动重载）

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 是 | 文件名，必须和目录里的文件完全一致（含扩展名） |
| `tags` | 是 | 从下面这些标签里挑，可以给一张打多个 |
| `note` | 否 | 这一张"长什么样、什么场合用"。**图上有字的必须写**，否则她不知道图上写了什么 |

可用标签：`笑` / `无语` / `骂` / `委屈` / `得意` / `撒娇`

## 几条实用建议

- **一张图一个主标签**最好用。多标签不是不行，但「无语」和「骂」挂太多会互相挤占，她反而挑不准。
- 表情包是"情绪"不是"图片"：与其放风景照，不如放能一眼看出态度的贴纸。
- 单张别超过 1MB：图片是以 base64 发出去的，体积会涨约 33%，太大会被 QQ 网关拒绝。
- 想让她少发：`config.json` 的 `stickers.perHour`（每小时上限，默认 3）调小。
- 想让她深夜不发：`stickers.quiet` 写成 `[23, 8]`（跨夜写法，23 点到次日 8 点）。

## 她为什么不发图

日志里会写原因，`grep "\[表情\]" bot.log` 能看到：

- `没有 <标签> 这个标签的图` —— 那个标签下一张都没有
- `这个小时已经发满 N 张` —— 限流
- `现在是静音时段` —— `stickers.quiet` 命中
- 什么都没打 —— 这一轮她压根没想发表情
